# Demo Script (2-minute video)

## Structure

1. **Problem (20 sec)**  
   Show a typical agent answering a live question with outdated or incomplete information. Highlight the confidence trap.

2. **Solution (30 sec)**  
   Introduce the live primary-data layer + MCP tools. Show one clean tool call returning source + timestamp.

3. **Before / After (40 sec)**  
   Side-by-side comparison:
   - Baseline agent (training data / web search)
   - Same agent grounded with Sugra MCP
   - Clear accuracy and citation difference

4. **Continuous Improvement (20 sec)**  
   Explain how live data creates a feedback loop that makes the agent better over time.

5. **Closing (10 sec)**  
   One-line summary + call to action.

## Key metrics to show

- Accuracy uplift (example: web search ~71% vs live data layer ~97%)
- Presence of source attribution and timestamps
- Reduced hallucinations on factual live questions
